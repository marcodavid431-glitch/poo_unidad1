 Sistema de Gestión de Contenido Audiovisual

Universidad Politécnica Salesiana
Materia: Programación Orientada a Objetos (POO)  
Descripción del Proyecto
Este proyecto es una aplicación desarrollada en Java para la consola, diseñada para gestionar diferentes tipos de contenidos multimedia 
(películas, series de televisión, documentales, podcasts y videojuegos) aplicando los principios de la Programación Orientada
a Objetos (herencia, polimorfismo y composición).
 Objetivos
* Administrar colecciones de contenido audiovisual mediante menús interactivos por consola.
* Aplicar clases abstractas y relaciones entre clases (como la composición de temporadas en las series).
* Utilizar estructuras dinámicas como `ArrayList` y control de entradas con `Scanner`.
 Ejecución
1. Clona el repositorio o descárgalo en tu computadora.
2. Abre el proyecto en tu entorno de desarrollo (como Apache NetBeans).
3. Ejecuta la clase principal que contiene el menú interactivo para registrar y visualizar los contenidos.
